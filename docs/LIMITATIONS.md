# Nirikshan-AI System Limitations & Compliance Scope

## Operational & Governance Boundaries

1. **Non-Accusatory Governance Principle**:
   * Nirikshan-AI is a decision-support system for administrative review.
   * The platform **never** automatically declares a project, agency, or individual guilty of fraud.
   * All outputs use neutral advisory tags (*Risk Indicator*, *Potential Anomaly*, *Requires Review*, *Potentially Similar Work*, *Photo Inconsistency*).

2. **Geotag & EXIF Metadata Dependencies**:
   * Verification depends on EXIF tags embedded by mobile devices during photo capture.
   * Photos stripped of metadata by messaging platforms (e.g. WhatsApp) are marked as `GPS metadata unavailable (Requires Review)` rather than penalized as fraudulent.

3. **Data Availability & Prototype Parameters**:
   * Initial risk thresholds (e.g., 500m distance cutoff, 0-100 weighting scheme) are representative prototype parameters designed for demonstration and hackathon evaluation.
